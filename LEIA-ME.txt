CONVERSOR-CONCEPT — EDIÇÃO GLOBAL COM SUPABASE

1. No Supabase SQL Editor, abra supabase-setup.sql.
2. Troque SEU_EMAIL_ADMIN@EXEMPLO.COM pelo e-mail real do administrador.
3. Execute o SQL.
4. Publique index.html, cloud-sync.js, manifest.json, sw.js e a pasta icons no GitHub.
5. Abra a página e use o botão Administrador.
6. No primeiro acesso, use Criar conta se ainda não existir um usuário Supabase Auth com esse e-mail.
7. Depois do login, Modo edição fica liberado. Alterações de texto, lâmpadas, imagens e vídeos são publicadas para todos.

Importante: o publishable key pode ficar no front-end; NÃO use service_role key no navegador.

MIGRAÇÃO DAS EDIÇÕES QUE JÁ ESTÃO NO SEU CELULAR/PC:
- Entre como Administrador no aparelho que contém as posições/textos corretos.
- Clique em “☁️ Publicar edição deste aparelho”.
- Isso envia os textos e posições já salvos localmente para todos os usuários.
- Imagens e vídeos antigos devem ser selecionados novamente uma vez para serem enviados ao Storage do Supabase.
